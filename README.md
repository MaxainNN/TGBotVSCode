# Quiz Telegram bot

## Description
This is bot that was made in educative purposes. Represent simple quiz telegram bot with 15 questions and 4 options for every question.

## Address :
```text
t.me/tianna1823_bot
```

## Commands

### Activate venv :
```bash
  python -m venv venv
  .\venv\Scripts\activate
```

### Install deps:
```bash
  pip install -r requirements.txt
```

### Run program:

```bash
  python bot.py
```
